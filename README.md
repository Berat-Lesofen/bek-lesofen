# Bek Lesofen — Kişisel Web Sitesi

Zihin, beden ve sistemler üzerine notlar içeren; tarih, felsefe, sosyoloji, teknoloji ve fitness odaklı kişisel web sitesi.

## Teknolojiler

- HTML
- CSS
- JavaScript

Framework, veritabanı veya API kullanılmaz.

## Yerelde çalıştırma

1. Proje klasöründeki `index.html` dosyasını çift tıklayarak tarayıcıda açın.
2. Dosyalarda değişiklik yaptıktan sonra tarayıcıyı yenileyin.

## İçerik düzenleme

Kişisel bilgiler, ana sayfa metinleri, kategoriler, yazılar ve iletişim bilgileri `content.js` dosyasında bulunur. Görünümü bozmadan içerik değiştirmek için öncelikle bu dosyayı düzenleyin.

## Dosya yapısı

```text
personal-website/
├── index.html    # Sayfa yapısı
├── style.css     # Tasarım ve responsive kurallar
├── content.js    # Düzenlenebilir site içerikleri
└── script.js     # Tema, menü ve kategori filtreleri
```
